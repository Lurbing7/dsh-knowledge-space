# 知识空间

把**本地目录**变成 DSH 的知识空间。文件不被复制、不被改写：插件在旁路建一份 SQLite 索引，你在 Obsidian 或任意编辑器里改完内容，点一次「增量索引」即可同步。

## 概念

一个空间由目录定义，涉及三个文件：

| 路径 | 用途 | 进 git |
|---|---|---|
| `<空间>/.dsh-knowledge-space/space.json` | 空间设置（扩展名、排除目录、敏感规则、上传目录） | 是 |
| `<空间>/.dsh-knowledge-space/manifest.json` | 每个已索引路径 + sha256 + 分块数 | 是 |
| `$DSH_HOME/knowledge-space/index/<id>.db` | SQLite FTS5 索引与逐文件状态 | 否 |

`manifest.json` 只在内容变化时重写，因此没改动的重建不会产生 diff。

## 支持的格式

| 格式 | 解析方式 | 引用定位 |
|---|---|---|
| `.md` / `.markdown` | 直接读文本，剥离开头 YAML frontmatter | 标题路径 |
| `.txt` | UTF-8，失败回退 GB18030（老的 Windows 中文文件） | — |
| `.pdf` | `unpdf` 抽取文字层，按页切分（受 `maxPdfPages` 限制） | 标题路径 + `p.N` |
| `.docx` | 解 ZIP 里的 OOXML；标题样式转为 Markdown 标题，表格转为行 | 标题路径 |
| `.xlsx` | 每个工作表转成 `行N：值 | 值` 的块 | 工作表名 + 行号 |

明确拒绝：`.doc`、`.xls`、`.ppt`、`.pptx`（报 `legacy_format`）；没有文字层的扫描 PDF（空文档）；扩展名骗人的二进制文件（前 8KB 含 NUL）。

## 索引

- 增量：先按 大小 + mtime 跳过，再用内容哈希兜底；被删掉的文件会从索引移除。
- 上限：单文件 `maxFileMB`（30）、PDF 页数 `maxPdfPages`（2000）、单文档字符 `maxDocChars`（200 万）、OOXML 的条目数与解压体积。
- 上传目录始终参与索引，即使它的父目录被排除。
- 隐藏文件/目录（以 `.` 开头）不遍历；符号链接跳过。

分块按标题对齐：一个块不跨标题，超长段落按句切分。

## 检索

基于 SQLite FTS5 与预分词文本：

- 中文连续段切成**重叠双字**，所以「事务」能命中「事务传播」；单字中文查询回退为子串扫描。
- 英文按单词保留；三个字符以上的查询走前缀匹配。
- 两列 FTS：`title`（相对路径 + 标题路径，权重 2.5）与 `body`（权重 1.0），BM25 排序。
- 重排：路径/标题命中加分；只靠路径命中的块会被降权而不是直接丢弃。
- 同一文档一次最多返回两段，避免一篇长文占满结果。

## git

- 空间设置与清单随所在仓库版本化，换设备能复现空间边界。
- 索引留在本机：它是派生数据，每次重建都全变。
- **自动提交**默认关闭。开启后，索引结束只对 `.dsh-knowledge-space/` 执行 `git add` 与 `commit`，从不 push、reset、clean。
- 面板只读取 `git status`；所有写操作都来自你按下的按钮。

## Agent 接入

- `knowledge_search`：返回带路径、标题、定位与敏感标记的排序片段。
- `knowledge_spaces`：列出空间及其文档/分块数量、上次索引时间。
- 系统提示会增加一段空间说明（设置里可关，或配置 `promptHint`）。刻意不实现"每轮自动检索"。

## 安全与隐私

- 不发起任何网络请求，不调用远端模型或索引服务。
- 面板的 HTTP 路由只接受本机（loopback）连接，跨源写请求直接拒绝。
- 敏感路径规则只做标记；把「索引敏感路径」关掉可彻底排除这些文件。
- 移除空间只删索引与本机登记，不动磁盘文件和 git 历史。

## 环境要求

- DSH `0.2.2-rc.3` 及以上（0.2 线内）。
- Node 24+（`node:sqlite` 在该版本默认可用）；DSH Desktop 自带。
- 运行时依赖只有 `unpdf`。
